# YimMenuV2 中文本地化版本

这是 [YimMenuV2](https://github.com/YimMenu/YimMenuV2) 的非官方简体中文版本，面向 GTA 5: Enhanced。

- 官方版本：[YimMenu/YimMenuV2](https://github.com/YimMenu/YimMenuV2)

## 其他工具

1. 防晒乳：[FSL](https://www.unknowncheats.me/forum/grand-theft-auto-v/616977-fsl-local-gtao-saves.html)
2. 注入器：[Xenos](https://www.unknowncheats.me/forum/general-programming-and-reversing/124013-xenos-injector-v2-3-2-a.html)

## 常见问题

### 每隔五分钟就与公共战局失去同步

我们目前没有BattlEye旁路，合法主机最终会因为心跳衰竭而移除你。目前除了使用真正的（私人）绕行线外，没有其他办法阻止这种情况。

### 移除 FSL 后游戏进度消失

FSL 会将账号存档数据重定向到本地磁盘，因此使用 FSL 产生的进度只会在启用 FSL 时显示。你也可以不使用 FSL 运行 YimMenuV2，但不建议这样做。

### 移除 FSL 后游戏无法启动

这是一个已知问题。删除 "Documents/GTAV Enhanced/Profiles" 后重试。
